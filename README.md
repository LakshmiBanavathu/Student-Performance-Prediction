# Student Performance Prediction System

## Project Overview
This project uses Machine Learning to predict student exam performance based on:
- Hours Studied
- Attendance
- Previous Scores

The project was implemented using Python, Scikit-learn, Pandas, Matplotlib, and Jupyter Notebook.

---

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Features
- Data preprocessing
- Exploratory Data Analysis
- Correlation Heatmap
- Linear Regression Model
- Performance Prediction
- Data Visualization
- Model Evaluation Metrics

---

## Machine Learning Algorithm
- Linear Regression

---

## Dataset
Kaggle Student Performance Factors Dataset

---

## Output
The model predicts student exam scores based on study patterns and academic history.
